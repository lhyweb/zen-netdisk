# 局域网网盘（Tornado）· V1.8

把本机一个文件夹变成网页，局域网内浏览器访问即可浏览 / 上传 / 下载文件，带账号分级权限、文件可见性、全局公告、站点标题自定义、回收站、日志、预览、多选打包、分享链接、新建文件夹、列表排序、**中英双语界面（i18n）** 与 **统一认证（SSO）回调预留**。

默认站点标题：**巡察工作组资料平台V202609**（管理后台「系统设置」可改，实时生效）。
默认端口：**8080**（`setup.ini` 可改）。

## 一、运行环境

- Windows / Linux（含信创统信等国产系统）/ Python 3.7+（本机为 `C:\python312\python.exe`）
- 已安装 Tornado：`C:\python312\python.exe -m pip install tornado`（Tornado 6.x 均可，含 6.2）
- **Python 3.7 兼容**：登录会话 Cookie 的 `SameSite=Lax` 属性在 Python 3.8+ 才附加；Python 3.7 的标准库不支持 `samesite`，代码已自动检测版本并省略，两套环境均正常（3.8+ 仍带 SameSite）

## 二、启动

```bash
cd netdisk
C:\python312\python.exe app.py
```

- 首次运行自动生成 `setup.ini`（端口 8080）与数据库
- 浏览器打开启动日志里打印的地址：
  - 本机：`http://127.0.0.1:8080`
  - 局域网：`http://本机IP:8080`（如 `http://192.168.x.x:8080`）
- 首次访问会跳转 `/setup`，**创建第一个管理员账号**：账号固定为 `admin`、用户名称固定为「系统管理员」（置灰不可改），密码自定义，并可为网盘设置站点标题（默认「巡察工作组资料平台V202609」）
- 本机（127.0.0.1）再次访问 `/setup` 时，若已有账号会自动以管理员身份登录
- 把地址告诉同事，登录后即可使用

## 三、常用操作

| 想做什么 | 怎么做 |
|---|---|
| 上传文件 / 上传文件夹 / 新建文件夹 | 路径栏最左：「上传文件」直接选文件；「文件夹 ▾」下拉＝上传文件夹 / 新建文件夹；**进入子目录后上传会保存到当前目录** |
| 下载 | 每行「下载」；多选（文件/文件夹均可勾选）后点路径栏「打包下载」可打 zip（批量条出现在路径栏最右，出现时隐藏上传提示） |
| 让某个文件对所有人可见/仅自己 | 点文件名右侧的「公开 / 私有」开关（颜色区分，无锁图标）；多选后可用「设公开 / 设私有」批量 |
| 分享一个文件给外人 | 点「分享」→ 复制链接（私有文件也能下，只读不可改；不改不可删） |
| 排序 | 默认按修改时间倒序；点「名称 / 大小 / 修改时间 / 上传者 / 可见性」表头可排序，再点反转 |
| 预览 | 图片点开弹窗预览（多张可 ← → 切换）；PDF 新标签打开；文本/代码可点「编辑」在线修改保存 |
| 切换中 / 英文界面 | 用户名下拉 →「语言切换」选 中文 / English（当前语言带 ✓），全站（含管理后台、登录、弹窗）生效 |
| 看公告 / 工作通知 | 顶栏「公告」（平台名旁）随时查看；管理员开启「登录自动通知」后每人每次登录自动弹一次（弹窗宽度随内容自适应，正文图片自动缩放） |
| 发布全局公告 | 右上角用户名下拉 →「系统管理」→ 管理后台 → 公告（标题/正文/图片/登录自动通知开关） |
| 自定义左上角网盘名称 | 管理后台 → 系统设置 → 站点标题（仅用户 ID 为 admin 的最高管理员可见；存数据库，实时生效） |
| 改自己的用户名称 / 密码 | 右上角点用户名 → 我的设置（用户名称可留空＝显示用户 ID；不得与他人用户 ID/名称重复） |
| 管理账号 | 用户名下拉 →「系统管理」→ 用户管理：新增用户、**批量新增用户**（每行一个 ID）、鼠标悬停用户 ID/用户名称点「修改」直接改（**admin 的用户 ID 锁定不可改**）、角色下拉切换、**重置密码（需两次输入确认）**、删除 |
| 看日志 / 看回收站 | 用户名下拉 →「系统管理」→ 管理后台（操作日志 / 回收站；回收站文件名以删除时间开头） |
| 重置系统 | 管理后台 → 系统设置 → 重置系统（清库，共享文件保留，需重新初始化管理员） |
| 统一认证（SSO）登录 | 登录页「跳转到统一认证登录」→ 跳转外部认证 → 回调 `GET /icbc?code=<base64 JSON>`（ID/id/username 键）自动登录；不存在的 ID 自动创建**待启用账户**并提示，待管理员启用后可用 |
| 查看作者信息 | 点击左上角品牌文字，或用户名下拉「关于」→ 弹出关于窗口（版本/作者/开源地址 + 设计说明，base64 存储） |

> 全局弹窗（提示 / 确认 / 输入）均为自绘虚化背景样式，不再调用浏览器原生 alert / confirm / prompt；全站输入框样式已统一；文件类型图标使用彩色通用 emoji（📷📕📃📄📁）。

## 四、账号角色

| 角色 | 权限 |
|---|---|
| 管理员 | 全部权限：管理账号、公告、站点标题、日志、回收站；可查看/修改/删除所有文件与文件夹 |
| 普通用户 | 上传自己的文件；管理（改可见性/覆盖/删除）自己的文件；可查看所有公开文件与管理员公开的文件 |
| 只读账号 | 只能浏览 / 下载 / 预览 / 复制分享链接，不能上传、修改、删除、建文件夹 |
| 待启用账户 | 不能登录；由管理员在后台改为其他角色后可用（供 SSO 自动创建的新账号使用） |

> 顶栏结构：平台名｜公告｜搜索｜用户名 ▾（我的设置 → 系统管理（仅管理员）→ 语言切换 → **关于** → 退出登录）；
> 路径栏：上传文件｜文件夹 ▾｜面包屑（批量操作条在多选时出现在路径栏最右侧）。

## 五、配置（setup.ini）

| 参数 | 默认 | 说明 |
|---|---|---|
| `[server] port` | 8080 | 监听端口 |
| `[server] root_dir` | ./files | 共享根目录（可改成任意路径，如 `D:/共享文件`） |
| `[server] max_upload_mb` | 500 | 单文件上传上限（MB） |
| `[security] session_hours` | 8 | 登录会话有效时长（小时） |
| `[security] secret_key` | 自动随机 | 签名会话与分享链接；**更换后所有会话与分享链接失效** |
| `[admin] username` | admin | 首次初始化时的管理员账号名 |

多实例：复制整个 `netdisk` 目录，改新副本的 `setup.ini`（端口 / 根目录 / 数据库路径），启动即为独立网盘，互不干扰。


- `files/_notice/`：公告图片

## 七、修改提示（给机主后续优化用）

- 改 Python 逻辑 / `templates/*.html` 后**重启服务**生效（Tornado 模板有缓存）
- 改 `static/app.js` 或 `static/style.css` 后，把 `templates/base.html` 里的 `?v=` 数字 +1（或浏览器 Ctrl+F5），避免旧缓存
- **新增界面文案**：同时在 `i18n.py`、`static/lang_zh.js`、`static/lang_en.js` 三处加同名 key，前端 `t('key')` / 后端 `L['key']` 自动生效
- 品牌「关于」弹窗的作者信息以 base64 内嵌在 `static/app.js` 的 `ABOUT_B64` 中，需修改时重新生成 base64（UTF-8）
- SSO 对接：登录页按钮地址在 `config.py` 的 `SSO_URL`（默认 `http://192.168.0.1/auth`）；回调签名校验在 `handlers/user.py` 的 `IcbcHandler`（已预留位置，本版不验签）
- `test_netdisk.py` 是一份端到端测试脚本（开发用，会自动清空数据重建账号），跑它前先停服务并删除 `netdisk.db*` 与 `files/`

## 八、常见问题

- **端口被占用**：改 setup.ini 的 port 为 8080 等并重启
- **别人访问不了**：确认本机防火墙放行该端口；确认和对方在同一局域网
- **上传大文件卡顿**：默认 500MB 上限，可调大 `max_upload_mb`（大文件上传为流式，不占内存）
- **忘了密码**：管理员在管理后台给该用户「重置密码」
- **忘记管理员密码**：删除 `netdisk.db` 重启，重新走 `/setup` 初始化（会清空账号与文件属性，共享文件本身不受影响）；也可在管理后台「系统设置 → 重置系统」一键清库（文件保留）
